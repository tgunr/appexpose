#  Description: AppExpose is a simple app that allows users to expose the application icons within a folder.

The application will scan a user specified folder for folders that contain applications. If any applications are found, a custom icon is created for the folder to represent the applicayions within the folder. The application runs a background task scanning the folders for any changes, additions, or deletions and updates the custom icon accordingly. 
The result is a useful indicator of which applications are contained within a folder.
The user can control the settings and enable or disable the display of the icons, control the amount and size of the generated icons, or restore the folder to its original look.
